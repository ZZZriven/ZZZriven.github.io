SICA：一个能够自我改进的编程智能体

A Self-Improving Coding Agent

Maxime Robeyns、Martin Szummer、Laurence Aitchison

首次提交 2025.04.21修订 2025.05.16 · v2
arXiv 原文阅读 PDF
IN A NUTSHELL

让编程智能体直接编辑自己的实现，借助反思、代码更新和基准反馈，逐步改善解决问题的方式。

01

研究问题

配备基本编程工具的智能体，能否通过编辑自己而提升表现？

02

核心方法

以语言模型驱动的反思和代码修改替代梯度更新，迭代调整组织模型调用和工具使用的智能体程序。

03

论文报告的结果

作者在 SWE-bench Verified 的随机子集上报告 17% 到 53% 的提升，并在其他编程评估中观察到增益。

04

阅读提醒本站判断

这一数字对应论文使用的随机子集，不应与完整 SWE-bench Verified 上的成绩直接比较。

THE RSI CONNECTION

与递归自我改进的关系

把智能体自身的实现作为优化对象，为系统层面的自我改进提供实证。
