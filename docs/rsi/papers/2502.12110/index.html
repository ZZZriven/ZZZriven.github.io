A-MEM: Agentic Memory for LLM Agents

A-MEM：新经验如何重组已有 memory

Wujiang Xu 等

Submitted 2025.02.17Verified Version 2025.10.08 · v11Note Updated 2026.09.12
arXivRead PDF
SUMMARY

将新经验写成结构化笔记，动态建立关联并更新旧 memory 描述，让 memory 组织随经验变化。

Improvement Target
Memory Structure & Semantic Representation
Feedback
新交互内容、检索到的历史笔记及 model 对关联和 context 属性的判断。
Evidence Scope
核验摘要、v11 元数据、正文第 3 节方法概览与第 4.3 节结果和 ablation；未复现实验。
01

Research Problem

保存日志并检索相似片段，难以捕捉分散在多次交流中的关系。预先规定图结构也可能限制新知识的组织方式。论文要解决的是历史经验怎样形成可调整的知识网络，支持后续 multi-hop 问答。

02

Insight本站解读

新的经历可以改变旧经历的解释，而不仅增加一条记录。A-MEM 将 memory 更新同时作用于链接与已有描述；编辑理解是，经验积累的价值取决于组织方式，memory 条目增长本身并不保证可用知识增长。

03

Observation

正文结果显示收益会随 foundation model 和题型变化，复杂 multi-hop 问题更能体现关联 memory 的作用，部分简单检索题型仍有强 baseline。去掉链接生成或 memory 演化的 ablation 表现下降，支持两种更新分别有贡献。

04

Method

每条交互先转为包含描述、关键词和标签的笔记，并生成向量表示。系统检索有关旧 memory，由 model 判断链接、调整旧笔记属性；回答时从更新后的 memory 网络取回相关内容，作为 reasoning context。

05

Results

作者在 LoCoMo 与 DialSim 长期对话任务中报告改善，并在多种 foundation model 上比较 memory 方法。第 4.3 节同时呈现不同任务的表现和 ablation，因此应理解为这些 memory 问答设置中的增益，而非通用能力倍增。

06

Limitations本站解读

可持续变化的是 external memory 及其关系，foundation model 与更新 workflow 没有一起演化。memory 之间相似不代表因果或事实一致；若 model 错误重写旧描述，后续检索也可能继承错误，论文成绩不能排除此类长期风险。

07

Outlook本站解读

编辑展望：需要在信息会撤回、关系会改变的持续任务中，跟踪错误 memory 如何被识别和修正。保持原始事件与改写版本的关联，并在冻结查询集和未来查询上分别评价，可避免只改善已有题型。

EDITORIAL NOTE · 本站判断

Relation to RSI

编辑归类为 Persistent System Improvement：系统保留经过重组的经验表示，用于之后的查询。它与仅在一次回答内追加 reflection 不同，但尚未展示 memory 更新器自身变强，因此不标为 Improver Self-Modification。
