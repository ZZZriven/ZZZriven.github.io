Voyager: An Open-Ended Embodied Agent with Large Language Models

Voyager：把一次次探索积累成 skill

Guanzhi Wang 等

Submitted 2023.05.25Verified Version 2023.10.19 · v2Note Updated 2026.09.12
arXivRead PDF
SUMMARY

结合自动 curriculum、可复用代码 skill library 与 environment feedback，让 Minecraft Agent 在探索中不断扩展能力。

Improvement Target
Skills & Memory
Feedback
Minecraft environment feedback、程序执行错误与 model 自我验证共同指导程序修订；成功程序进入 skill library。
Evidence Scope
本条基于 arXiv 摘要与版本历史核验，未核读全文。迁移证据限定于作者的 Minecraft 设置，没有覆盖一般真实环境。
01

Research Problem

开放环境中的 Agent，怎样保留并复用过去学到的行为？

02

Insight本站解读

Voyager 把成功经验存为可执行代码 skill，使学习成果能被检索、组合并用于后续探索。自动 curriculum 负责决定下一步学什么，skill library 负责保留已学内容；model 能力与系统能力由此可以分开观察，后者能在不更新参数时持续积累。

03

Observation

摘要报告相较既有方法发现更多独特物品、探索更远距离并更快达到技术树里程碑，也展示 skill library 用于新的 Minecraft 世界。其 feedback 包括环境状态、执行错误与自我验证，实际积累的是可复用行为，并非 foundation model 的新 weights。

04

Method

自动选择探索任务，将成功行为存为可执行 skill，并通过 execution feedback 迭代修正程序。

05

Results

论文报告更丰富的物品发现与更快的里程碑达成，并展示 skill library 在新世界中的迁移。

06

Limitations本站解读

改进主要保存在 skill library 和 context 中，不涉及 foundation model 参数更新。

07

Outlook本站解读

编辑展望：可比较 skill 检索失败、过时 skill 与 skill 冲突怎样影响长期表现，再考察压缩和淘汰机制。更强的迁移验证应改变世界规则与任务组合，确认 skill library 积累的是可组合能力，而不仅是适合原环境的一组程序。
