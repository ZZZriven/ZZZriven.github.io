CLIN: A Continually Learning Language Agent for Rapid Task Adaptation and Generalization

CLIN：把试错压缩为可迁移的 causal memory

Bodhisattwa Prasad Majumder 等

Submitted 2023.10.16Verified Version 2023.10.16 · v1Note Updated 2026.09.12
arXivRead PDF
SUMMARY

从每次成功或失败中提炼带不确定性的因果经验，在不更新 model parameters 时改善后续任务与环境适应。

Improvement Target
Cross-Trial Experience & Causal Memory
Feedback
模拟器动作观察、最终任务 reward 转成的文字 feedback，以及以往试次 memory。
Evidence Scope
核验摘要、v1 元数据及正文第 3.1–3.3 节；迁移结论依据作者摘要，未复现 benchmark。
01

Research Problem

Agent 可以在失败后重试同一任务，却常把教训写成仅适合当前地点的 prompt。论文研究冻结 model 如何保留更一般的行动知识，使环境配置或任务变化后仍能利用过去试错，而非完全重新探索。

02

Insight本站解读

把经验表述成某行动是否有助于某状态变化，更接近可迁移的行动 model。CLIN 还在文字中保留不确定性；编辑理解是，这能把暂时观察与稳定规律区分开，减少一次失败被误写成普遍规则。

03

Observation

正文明确让 memory cross-trial 保留，并进一步从多个任务的较好试次构造元 memory。生成的经验数远少于行动数，显示 memory 在压缩历史；摘要也报告新环境与新任务上的迁移收益，超出只修补本题。

04

Method

控制器结合任务和 memory 提出子目标，executor 转成有效环境动作。试次结束后，memory generator 综合轨迹与结果，更新关于必要动作或无贡献动作的半结构化句子，再从跨任务经验生成更一般的元 memory。

05

Results

作者在 ScienceWorld 中报告同任务重复尝试的持续改善，也在新环境或任务上观察到 zero-shot 迁移及后续适应。结果对应文本模拟器和所用 model，支持 memory 层的累积收益，不能外推到任意开放环境。

06

Limitations本站解读

因果抽象由 language model 根据有限轨迹生成，并非通过严格干预实验识别的因果规律。控制器、executor 和 generator 均冻结；环境还提供可行动作信息，所以表现包含模拟器接口对 search 空间的帮助。

07

Outlook本站解读

编辑展望：适合测试错误规律进入 memory 后能否被反例推翻，并将环境变化分为配置变化与规则变化。另可用清空 memory、保留原始轨迹和保留抽象三种对照，衡量抽象到底提供了多少跨任务收益。

EDITORIAL NOTE · 本站判断

Relation to RSI

编辑归类为 Persistent System Improvement：更新后的经验会影响未来试次和不同任务，而非只修订当前输出。其贡献在于学习产物的保留与迁移；memory 生成算法仍固定，没有证明负责下一轮学习的程序自身被改进。
