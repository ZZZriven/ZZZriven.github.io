Promptbreeder：同时进化任务提示与变异提示

Promptbreeder: Self-Referential Self-Improvement Via Prompt Evolution

Chrisantha Fernando、Dylan Banarse、Henryk Michalewski、Simon Osindero、Tim Rocktäschel

首次提交 2023.09.28已核实版本 2023.09.28 · v1解析整理 2026.09.12
arXiv 原文阅读 PDF
ABSTRACT / 摘要

不仅搜索更好的任务提示，还修改负责产生这些提示的变异提示，是在固定进化框架内研究改进策略自修改的案例。

改进对象
任务提示与提示改进策略
反馈来源
带答案的任务训练集提供适应度；种群选择保留优胜个体；变异提示被更新后继续控制下一轮提示生成。
证据边界
已核验 arXiv 摘要与 v1 历史，正文第 3 节个体构成、选择及第 3.2 节变异机制；未复现实验。
01
RESEARCH PROBLEM

研究问题

手写提示容易受具体任务和设计者经验限制，固定的提示改写策略也可能阻碍搜索。论文研究能否让语言模型进化任务提示，同时调整产生提示变体的规则，使下一轮搜索采用由系统自己更新的改进策略。

02
INSIGHT

核心洞察本站解读

如果变异规则也用自然语言表示，生成器就可以把自己的操作条件作为可编辑对象。由此可区分直接改进任务提示和改进产生提示的方法：后者会影响下一轮候选的分布，是本文自指机制的核心。

03
OBSERVATION

关键观察

一个进化个体同时保留任务提示、变异提示以及可选的成功推理示例，任务适应度决定选择。论文展示变异提示能够被超变异操作更新；但决定使用哪些操作以及如何评估个体的外层框架仍由研究者预设。

04
METHOD

方法解析

初始化多样化提示种群，在训练题目上评估任务表现，以锦标赛选择保留更好的个体。语言模型执行直接改写、分布式变异等操作；超变异会重写变异提示，更新后的变异提示再参与后续任务提示生成。

05
RESULTS & EVIDENCE

实验与结论

作者报告，进化出的提示在算术与常识推理基准上超过所比较的人工提示策略，并能产生适用于仇恨言论分类的复杂提示。实验验证了有限任务域中的提示进化，不意味着语言模型底层参数或通用能力持续增加。

06
LIMITATIONS

局限与边界本站解读

适应度来自带答案的训练任务，基础语言模型、外层选择算法和超变异机制仍固定。可编辑对象主要是提示文本，结果受任务分布与评估预算制约；这里的自修改范围不能延伸为完整系统任意重写和无界进步。

07
OUTLOOK

未来展望本站解读

编辑展望：应在相同候选生成和评估预算下比较固定变异与可变异改进策略，并检验学到的变异提示能否迁移到新任务。这样才能分离改进器更新的实际贡献与单纯扩大提示搜索数量带来的收益。

THE RSI CONNECTION · 本站判断

与递归自我改进的关系

变异提示承担后续候选生成的改进职责，并能由系统重写后投入下一轮，因此归为受限的改进器自修改。主分类落在智能体与代码方向的提示策略层，明确其不修改模型权重或全部进化程序。
