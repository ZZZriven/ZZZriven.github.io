STaR: Bootstrapping Reasoning With Reasoning

STaR：从自己的 reasoning 中学习 reasoning

Eric Zelikman 等

Submitted 2022.03.28Verified Version 2022.05.20 · v2Note Updated 2026.09.12
arXivRead PDF
SUMMARY

从少量 reasoning 示例出发，生成并筛选能得到正确答案的 reasoning 过程，再将这些过程用于迭代 fine-tuning。

Improvement Target
Model Weights
Feedback
数据集正确答案用于筛选 reasoning；失败时也作为重新生成 reasoning 的条件，另有少量人工 reasoning 示例启动。
Evidence Scope
本条基于 arXiv 摘要与版本历史核验，未核读全文。验证信号主要是最终答案，不能自动保证中间 reasoning 忠实或逻辑正确。
01

Research Problem

如何在缺少大规模人工 reasoning 标注时，训练 model 生成有效的 reasoning 过程？

02

Insight本站解读

STaR 利用答案监督筛选 model 自己生成的 reasoning，将原本缺少中间步骤的数据转化为训练材料。失败题可以借助正确答案再生成解释，使训练覆盖更多问题；关键机制是生成、验证与 fine-tuning 的循环，而不是把所有自生成文本都当作正确知识。

03

Observation

作者报告多个数据集上，迭代学习合格 reasoning 优于直接 fine-tuning 预测最终答案，并在 CommonsenseQA 上与更大 model 的 fine-tuning 结果比较。方法仍使用正确答案和少量 reasoning 示例，结果支持自生成 reasoning 的训练价值，不能据此认定所有 reasoning 过程都正确。

04

Method

生成 reasoning、筛选正确结果；失败时提供正确答案尝试反推，再用合格 reasoning fine-tuning 并重复。

05

Results

论文在多个数据集上观察到，相比直接训练预测答案，迭代学习自生成 reasoning 更有效。

06

Limitations本站解读

仍需要题目、正确答案及少量 reasoning 示例，不能理解为完全摆脱外部监督。

07

Outlook本站解读

编辑展望：可以增加对中间步骤的独立验证，区分答案碰巧正确与 reasoning 有效的样本，并检查答案条件化生成是否产生事后解释。进一步比较数据多样性、筛选阈值与迭代轮数，有助于找出 self-training 何时增益、何时开始强化偏差。
