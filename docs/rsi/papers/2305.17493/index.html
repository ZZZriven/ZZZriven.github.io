The Curse of Recursion: Training on Generated Data Makes Models Forget

Model Collapse：Recursive Training 如何丢失 Distribution Tails

Ilia Shumailov 等

Submitted 2023.05.27Verified Version 2024.04.14 · v3Note Updated 2026.09.12
arXivRead PDF
SUMMARY

分析后代 model 不断学习前代 synthetic data 时的分布退化，展示低概率事件信息逐渐丢失，为 self-generated data 训练提供必要的边界视角。

Improvement Target
Training Distribution & Multigeneration Learning
Feedback
前代 synthetic data；研究独立真实分布信息缺失的影响
Evidence Scope
特定 recursive training 设置的理论与实验；不等于所有 synthetic data 必然失效
01

Research Problem

如果后续 model 越来越多地学习前代 model 生成的内容，原始数据分布还能被保持吗？论文关注即便任务本身没有变化，重复生成、抽样和拟合也可能造成的代际信息损失及长尾行为退化。

02

Insight本站解读

有限样本和近似拟合会遗漏低概率事件；当下一代把上一代的输出当作现实样本时，这些误差可能被继承和放大。因此训练损失下降或常见模式保持，并不足以说明整体分布被忠实保留。

03

Observation

作者区分早期尾部信息流失与后期分布明显收缩，并在高斯混合、变分自编码器和 language model 设置中研究现象。正文特别说明，language model fine-tuning 实验中主要检测到早期信号，应避免把所有实验描述成彻底失效。

04

Method

先利用离散分布、单维高斯和带噪近似 model 建立理论直觉，再执行多代 synthetic data 训练实验，观察分布与原始数据的偏离。方法重点是跟踪生成—采样—再学习链条，而非提出一种提高 model 成绩的训练算法。

05

Results

论文展示特定 recursive training 设置下的分布退化，指出尾部覆盖和原始数据的重要性。这为无筛选地反复使用 synthetic data 提供了反例，但没有证明经过验证、保持多样性或保留真实数据的合成训练必然失败。

06

Limitations本站解读

理论结果依赖采样与近似 model 假设，实验也有具体的数据替换及训练配置。本条核读定义、理论动机和实验概览，未逐项验证定理；不能将结果扩大为所有 self-training、蒸馏或带执行验证的方法都会坍缩。

07

Outlook本站解读

编辑展望：更有价值的后续比较，是在相同预算下改变真实数据保留率、feedback 验证强度和 curriculum 多样性，并同时测量任务正确率与长尾覆盖。这样才能判断某个改进循环何时积累知识、何时放大偏差。

EDITORIAL NOTE · 本站判断

Relation to RSI

编者归类：这是 RSI 数据循环的边界研究，表明自生成经验的数量增长可能伴随信息减少。它应与 STaR、Absolute Zero 等有筛选或环境验证的机制对照，检查各自如何补充或保留有效信号。
