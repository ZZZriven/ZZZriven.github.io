AI4AI-Bench: Benchmarking LLM Agents in Algorithmic Design for Recursive Self-Improvement

AI4AI-Bench：Agent 能否改进 model 的学习算法？

Yizhe Chi 等

Submitted 2026.08.20Verified Version 2026.08.20 · v1Note Updated 2026.09.12
arXivRead PDF
SUMMARY

把训练算法本身设为优化目标，借助固定任务、独立重跑与隐藏评测，区分改变 model 学习方式和只改运行流程。

Improvement Target
Independent Evaluation of Learning Algorithm Design
Feedback
固定开发预算内的实验 feedback；最终由隐藏 evaluator 对从头重跑的候选算法评分。
Evidence Scope
核验 arXiv v1 摘要与首次提交记录；归一化得分仅在论文定义的尺度和任务范围内解释。
01

Research Problem

自动研究任务的收益可能来自数据收集、超参数或运行优化，而不是更好的学习规则。论文尝试单独衡量 Agent 能否设计训练目标或参数更新方法，从而改善后续 model 训练过程。

02

Insight本站解读

应把候选算法从 search 过程分离，再在固定条件下重新训练并评分。本站解读：这种隔离有助于区分工程提速和学习机制的改变；两者都可能有用，但对 recursive optimization 研究回答的是不同问题。

03

Observation

摘要中的多数提交并未真正改变 model 如何学习；少数改变学习机制的提交获得更高平均分。增加 reasoning 投入与更多机制层修改相关，但这些观察不能单独说明投入与性能之间具有普遍因果关系。

04

Method

在十个冻结的研究任务中，给 Agent 固定开发时间与计算资源修改训练算法；随后从头重跑候选，由 Agent 不可见的固定 evaluator 打分。不同任务指标被映射到同一归一化尺度后再汇总比较。

05

Results

摘要报告六种系统共 29 个配置的平均归一化分数为 0.166，最好系统为 0.250；原算法在该尺度上为 0.1。这里是论文定义的归一化得分，不是准确率，也不是已经实现 recursive optimization 的比例。

06

Limitations本站解读

一次算法设计评测不包含改进后的 model 成为下一代研究者的完整闭环。固定任务与归一化尺度的选择影响汇总解释，search 预算也限制结论范围；此条目核验摘要，未审计全部提交或复现训练。

07

Outlook本站解读

本站展望：在独立评测基础上增加跨 model、跨任务和跨预算迁移，并追踪改进后的训练方法能否培养更好的下一代研究者。还需要公布失败分布，检查均值是否主要由少量任务或偶然成功推动。

EDITORIAL NOTE · 本站判断

Relation to RSI

归入 Evaluation & Limits、关联类型为 Surveys, Theory & Evaluation。它测量改进 model 生产过程的一项必要研究能力；只有进一步让产生的改进回到研究系统，并验证后续改进效率，才触及系统自身的 recursion 问题。
