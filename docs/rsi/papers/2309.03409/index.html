Large Language Models as Optimizers

OPRO：用历史候选与分数驱动 prompt optimization

Chengrun Yang、Xuezhi Wang、Yifeng Lu 等

Submitted 2023.09.07Verified Version 2024.04.15 · v3Note Updated 2026.09.12
arXivRead PDF
SUMMARY

把先前候选及其分数写入 meta-prompt，让 language model 持续提出更优 prompt；optimizer 本身保持固定，更新的是目标系统的任务 instruction。

Improvement Target
Task Prompts & Candidate History
Feedback
目标 model 在带答案训练样本上的准确率为候选评分；候选 prompt 与分数写入 meta-prompt，驱动下一轮生成。
Evidence Scope
已核验 arXiv 摘要与 v3 历史，正文第 1—2 节 meta-prompt 设计和第 3 节小规模数学优化现象；未复现实验。
01

Research Problem

prompt 空间离散、巨大且通常只能通过 model 调用测量表现，难以使用常规 gradient 优化。论文研究 language model 能否从自然语言目标及过往候选分数中识别改进方向，自动 search 能在新样本上提高任务准确率的 instruction。

02

Insight本站解读

历史候选和分数构成一种可读的 optimization trajectory，model 不必只围绕当前最好 prompt 作局部修改，而可以比较多个尝试来提出新 strategy。任务描述和示例提供语义约束，实际运行得分则决定候选是否值得进入下一轮历史。

03

Observation

作者发现不同 model 会产生风格不同的 instruction，仍可沿 optimization trajectory 提高任务表现。小规模数学优化示例也显示，初始区域距离目标更远时问题更困难；能根据分数提出合理下一步，并不等于具备通用 optimizer 的稳定性。

04

Method

meta-prompt 包含任务说明、示例及已评估的候选与分数；optimizer model 生成新 prompt，目标 model 在训练样本上运行并计算准确率。把新 prompt 和得分加入历史，继续生成，直到不能改进或达到预算，再采用选出的任务 prompt。

05

Results

论文在 GSM8K 与 Big-Bench Hard 上报告，search 到的 prompt 超过所比较的人工 prompt，并观察到同领域任务的迁移收益。结果反映特定 model、起点和训练样本下的 prompt optimization，摘要中的最大提升不应视为普遍平均收益。

06

Limitations本站解读

训练样本及可计算评分是必要外部信号，反复选择也可能 overfitting 小型训练集。context 预算限制可利用的历史，foundation model 与元优化流程固定；外部数学问题的解变好与部署系统的长期能力改进需分别记录。

07

Outlook本站解读

编辑展望：后续应使用独立 validation set 决定停止和候选选择，并报告 prompt 在任务漂移及 model 版本变化后的保留效果。还可比较完整历史、压缩历史和失败样本 feedback，检验改进到底来自轨迹 reasoning 还是更大规模的候选尝试。

EDITORIAL NOTE · 本站判断

Relation to RSI

主应用是为目标 model 寻找可复用任务 prompt，因此归为 Agents & Code 中的 Persistent System Improvement。固定 optimizer 改变目标系统配置，并未修改自身负责下一轮优化的规则；数学候选 search 只是附带的产物优化示例。
