Self-Instruct: Aligning Language Models with Self-Generated Instructions

Self-Instruct：用自生成 instruction 训练 instruction following 能力

Yizhong Wang、Yeganeh Kordi、Swaroop Mishra 等

Submitted 2022.12.20Verified Version 2023.05.25 · v2Note Updated 2026.09.12
arXivRead PDF
SUMMARY

由少量人工种子任务扩展 instruction、输入与答案，经筛选后，再训练原 model，是自生成监督进入 model weights 的基础方法。

Improvement Target
Training Data & Model Weights
Feedback
人工种子任务确定初始范围；synthetic data 经过相似度、重复与格式筛选，最终答案作为 supervised fine-tuning 目标。
Evidence Scope
已核验 arXiv 摘要、版本历史及正文第 2 节方法、第 4 节数据规模与质量分析；未复现实验。
01

Research Problem

instruction tuning 依赖人工编写任务与答案，成本之外还受任务多样性限制。论文研究能否从少量种子任务出发，让 pretrained model 生成足够丰富的监督，再用于提升同一 model 对新 instruction 的适应能力，并通过独立任务检验效果。

02

Insight本站解读

model 已有的知识未必能直接转化为稳定的 instruction following 行为；让 model 先构造任务与示例，再把这些示例整理成训练信号，可以把分散能力转成可调用行为。关键是监督的组织与筛选，而不是把所有自生成答案都当成事实。

03

Observation

作者发现先生成输入再给答案，会使分类任务偏向某些标签，因此改为先列标签再生成对应输入。数据规模与质量实验也显示，更大且更高质量的 instruction 集能够继续改善表现，说明生成量和监督可靠性需要分别考察。

04

Method

以人工种子任务建立任务池，混合抽取人工和已生成 instruction 作示例；model 依次生成新 instruction、判断任务类型，再按类型生成输入输出。通过相似度、重复与格式规则过滤数据，最后以标准 supervised learning fine-tuning 原 model。

05

Results

论文在 Super-NaturalInstructions 上报告，相对原始 GPT3 的分数提高 33 个百分点；新编 instruction 的人工评价同样显示改进。结果支持自生成 instruction 作为训练资源的有效性，不能由此推断每个合成答案都正确。

06

Limitations本站解读

方法仍依赖人工种子任务及 pre-training 知识，启发式去重也不等于事实验证。正文主要展示数据池扩展后对原 model 的 fine-tuning，没有证明更新后的 model 反复接管数据生成后，能力还能跨多个训练循环持续增长。

07

Outlook本站解读

编辑展望：应追踪多轮 model 更新后任务覆盖、答案错误率与保留能力的共同变化。可以加入独立 verifier 及新任务 held-out set，检验 generator 变强后是否带来更好的下一轮监督，而非仅让 instruction 形式越来越接近训练集。

EDITORIAL NOTE · 本站判断

Relation to RSI

方法使用自生成并筛选的 instruction 数据 fine-tuning 原 model，参数变化保留在目标系统中，因此属于 Persistent System Improvement。实验没有展示 fine-tuning 后的 model 反复接手多轮数据生成，也没有改写数据生成或训练算法，不能据此认定 Improver Self-Modification。
