HOW TO READ THE FIELD

先辨清，什么在改进。

01 / METHODOLOGY

本站综合 Awesome RSI 与自进化综述建立阅读分类：以主要研究对象划分七个方向，再独立标注与 RSI 的关联。它是便于检索的编辑分类，并非统一的学界分级。

01

改进对象 WHAT

区分当前输出、记忆与技能、模型与奖励、智能体代码，以及自动搜索与科研。综述和评测单独归类。

02

改进闭环 HOW

反馈从哪里来？哪些变化被保留？改进器本身是否更新？每篇都记录改进对象、反馈来源和 RSI 关联判断。

03

证据边界 EVIDENCE

结合独立评测、迁移能力、迭代轮数与计算成本读结果。任务分数提高，不能直接推出开放式递归改进。

单次输出修订

修订当前回答，无持久系统更新。

持久自我改进

权重、记忆或代码保留到后续尝试或任务。

递归机制探索

改进机制也参与更新；仍须读其边界。

基础与评测

综述、理论、评测或局限研究。

框架参考 LobeHub Awesome RSI ↗ 的范围区分，以及 Prism-Shadow Awesome RSI ↗ 的方法与评测维度。后者的 RSI mode 指 Online / Offline，和本站“关联类型”不是同一维度。
