HOW TO READ THE FIELD

先辨清，什么在改进。

01 / METHODOLOGY

以 Research Problem 划分七个研究方向，再以 RSI Relation 独立标注系统更新方式。分类同时覆盖具体方法、相关能力、外部产物优化，以及 survey、theory 与 evaluation；不把所有改进都视为 Recursive Self-Improvement。

01

Improvement Target

先定位论文的核心问题：output、memory、model、Agent，还是 search 与 discovery。以 evaluation 或 survey 为主要贡献的论文，分别归入对应研究方向。

02

Update Mechanism

明确被优化的系统边界：变更是否保留？是固定 optimizer 更新目标系统，还是更新后的 improver 接手下一轮？外部 artifact 变好需单独说明。

03

Evidence Scope

结合 independent evaluation、transfer、iteration 数量与 compute cost 读结果。任务分数提高，不能直接推出 open-ended Recursive Self-Improvement。

Output Refinement

改写当前任务输出，不保留系统更新。

Persistent System Improvement

weights、prompt、memory 或 code 进入后续尝试或任务；optimizer 可以固定。

Improver Self-Modification

显式改写承担后续改进的程序或 strategy，并由改后版本继续改进。

Enabling Methods & Artifacts

主要研究相关能力或外部产物优化；混合实验逐篇说明系统更新范围。

Surveys, Theory & Evaluation

用于组织 taxonomy、建立 theory、开展 evaluation 或分析 limitations。

主标签概括论文的主要贡献，混合实验的更新方式在解析中分别说明。这些标签不是能力排名。标题中的 “self-improving” 或 “recursive” 本身不构成分类证据；每篇解析说明 target、feedback 和 update scope。model 与 reward model 共同训练归入 Persistent System Improvement，不能仅据此认定 improver 已 self-modify。

From Optimization to Self-Modification

  1. Self-Rewarding Language Models
  2. Self-Taught Optimizer (STOP): Recursively Self-Improving Code Generation
  3. Darwin Godel Machine: Open-Ended Evolution of Self-Improving Agents

Evaluating Self-Improvement
